# Authored text of the customer implementation packs

These TypeScript files are the authored text (systems, integrations, identity, permissions, network, connectors, local development,
rollout, discovery, troubleshooting, acceptance criteria) that the BrainSiphon site merges into the generated Customer Implementation
Playbook for each of the ten use cases that have an executable pack in `../`. They are kept here as the readable source of what the
packs document. The free site publishes only the card and UPI fraud pack.
