- **Name and version:** ____________

- **Baseline model:** A threshold on traffic below a fraction of the cell's rolling median, because it is simple and operators already use it.
- **Production model:** A peer-conditioned residual detector with a classifier over KPI patterns, scored every 15 minutes and routed with the topology so field and remote teams see the suspected cause.
- **Intended use:** Detect cells that appear healthy to the alarm system but carry no traffic or serve users badly, so silent outages are found in minutes not days.
- **Out of scope:** - Alarm count: the failure is silent.<br>- Software version alone: weak link.<br>- Cell age: unrelated.
- **Primary metrics:** - Precision and recall on confirmed silent outages<br>- Time to detect against later alarms<br>- False alarms per 1000 cell-days
- **Measured values (fill in):** ____________

- **Calibration:** Calibrate scores so that a score of 0.02 means a 2% event rate on the current population, per segment, because thresholds and costs are applied to the probability, not the rank.

- **Human oversight:** human-on-the-loop: The system acts within a bounded action space and a person monitors, samples and can halt it. The uncertain band routes to a review queue with a time limit.
